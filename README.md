# ずし保育園ハザードマップ

逗子市内の保育施設と、津波・土砂災害の公開ハザード情報を同じ地図で比較する静的Webサイトです。

## データについて

- 施設情報: 逗子市「市内保育施設一覧」
- ハザード情報: 国土地理院「重ねるハザードマップ」公開タイル

一覧に表示する判定は住所検索による周辺情報であり、園舎そのものが区域内にあることを断定するものではありません。最終的な判断には、自治体・施設の最新情報と現地確認を利用してください。

## ローカル起動

```sh
python3 -m http.server 4173
```

ブラウザで `http://127.0.0.1:4173/` を開きます。
